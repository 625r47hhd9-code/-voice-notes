VOICE NOTES — React v9.3

Собрано по утверждённой логике интерфейса.

ГЛАВНЫЙ ЭКРАН
- показывает только заметки выбранного дня;
- свайп влево → следующий день, ещё свайп → ещё следующий день;
- свайп вправо → предыдущий день;
- плашка даты остаётся на одном месте;
- сегодняшний день отдельно выделен меткой «Сегодня»;
- список заметок прокручивается вертикально;
- есть ввод текста с клавиатуры;
- голосовая запись без указанной даты попадает на открытый день;
- напротив каждой заметки есть •••.

••• У ЗАМЕТКИ
- открывает перенос заметки;
- сверху переключатель «Дата / Категория»;
- «Дата» — календарь для переноса на конкретный день;
- «Категория» — перенос в выбранную группу;
- при переносе заметка не дублируется.

КАЛЕНДАРЬ
- утверждённый вариант №3;
- переключатель «Календарь / Список»;
- под календарём ближайшие даты с задачами;
- точки отмечают дни с задачами;
- выбор дня открывает этот день на главном экране.

РАЗДЕЛЫ
- нижних вкладок нет;
- снизу компактная выезжающая шторка;
- группы расположены горизонтально;
- группы можно прокручивать по горизонтали;
- нажатие группы открывает отдельный экран;
- внутри группы: заметка + подзаметки.

ИНСТРУМЕНТЫ
- сотрудники, календарь, калькулятор и блокнот находятся в отдельном меню «Инструменты» (кнопка ▦ сверху);
- сотрудники не дублируются среди групп главного экрана.

КАЛЬКУЛЯТОР
- сохранён утверждённый дизайн;
- вкладки «Основной / Научный / Конвертер»;
- история вычислений хранится в localStorage;
- память mc / m+ / m− / mr;
- скобки, %, квадрат, куб, корни, степень, sin/cos/tan и основные функции;
- конвертер длины, площади, объёма и массы.

БЛОКНОТ
- текст с клавиатуры и голосом;
- рисование одним пальцем;
- ластик и очистка;
- галерея листов с текстом и рисунками;
- масштабирование полностью убрано;
- жест двумя пальцами не масштабирует лист.

ГОЛОС
- одно нажатие 🎙 — начать;
- второе — сохранить;
- во время распознавания показывается живой текст;
- есть удаление последнего слова;
- аудиофайл не сохраняется.

Версия: React v9.3
