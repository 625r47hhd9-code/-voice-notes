Голосовой ассистент v8.4

Изменения:
- шапка Блокнота адаптирована под safe area iPhone 11 — заголовок не должен попадать под «чёлку»;
- перелистывание листов Блокнота свайпом отключено: лист выбирается только через список листов;
- микрофон работает как переключатель: одно нажатие — начать запись, второе — закончить;
- во время диктовки отображается распознаваемый текст в реальном времени;
- добавлена кнопка «⌫ слово» для удаления последнего распознанного слова до сохранения;
- при выходе/назад активная диктовка принудительно отменяется, кнопка больше не должна зависать;
- слова даты и дня недели удаляются из текста задачи;
- «в среду съездить на рыбалку» создаёт задачу на ближайшую среду с текстом «съездить на рыбалку»;
- выбор даты в календаре теперь открывает планер именно на выбранной дате;
- версия и кэш обновлены до v8.4.
