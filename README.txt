Голосовой ассистент v7.4

Изменения:
- «Сотрудники» убраны из групп на главном экране; остаются отдельной нижней вкладкой.
- Группы переделаны по принципам приложения «Заметки» на iPhone: компактные строки-папки, счетчик справа, стрелка перехода, тонкие разделители.
- Голосовой ввод сохранен отдельным фирменным блоком.
- Сохранены псевдонимы сотрудников и рисование в блокноте.
